# UpsurgeERP Frontend

Educational Institution Management System - React Frontend

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- Backend API running on port 3000

### Installation

1. **Install Dependencies**
```bash
cd frontend
npm install
```

2. **Start Development Server**
```bash
npm run dev
```

Frontend will start at: `http://localhost:3001`

## 📁 Project Structure

```
frontend/
```

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **UI Library**: Material-UI (MUI)
- **Routing**: React Router v6
- **HTTP Client**: Axios
- **Charts**: Chart.js
- **Forms**: Formik + Yup
- **Notifications**: React Toastify
- **Real-time**: Socket.io Client
